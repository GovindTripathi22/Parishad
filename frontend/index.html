        What this does in simple words:
        The comprehensive user manual. Look here to find out what every button does, when to use it, who has permission to use it, and how to navigate to any feature.
      

    


    

      
      
      

        

          verified
          1. Interactive Console & Presets
        

        
What it does & When to use:

        

          Evaluates any engineering update (pull request, commit message, Jira ticket, or Slack chat) against official specifications.
          Use it before merging code or pushing firmware changes to check for safety or policy violations.
        

        

          
• Who can use: All Engineers, Tech Leads, QA Analysts, and Product Managers.

          
• How to navigate: Click 01 Console in the top header or press Experience Console.

          
• Key Buttons: Verify Update runs the 4-stage pipeline; the 4 preset scenario pills instantly load realistic examples.

        

      


      
      

        

          rate_review
          2. Human Safety Gate & Diff Review
        

        
What it does & When to use:

        

          Provides a side-by-side comparison of the certified baseline specification vs the proposed new text. 
          Use this whenever an automated conflict is detected to review the impact, optionally edit proposed phrasing, and record an audit note.
        

        

          
• Who can use: Engineering Leads, Safety Officers, and System Architects.

          
• How to navigate: Click 02 Safety Gate in the header or the Review & Sign Off link in any conflict card.

          
• Key Buttons: Approve & Save (⌘↵) updates the spec and writes to the ledger; Decline rejects the change and preserves the baseline.

        

      


      
      

        

          psychology
          3. Company Brain & Vision OCR
        

        
What it does & When to use:

        

          Enables natural-language questions grounded in verified specifications. Also allows uploading or scanning images of physical hardware datasheets to extract parameters via Multimodal Vision OCR.
        

        

          
• Who can use: Anyone on the team needing official limits or adding new specifications.

          
• How to navigate: Click 03 Company Brain in the header or press ⌘K anywhere.

          
• Key Buttons: Ask for citation answers; Scan Datasheet (OCR) or drag-and-drop to upload images; Index Document to commit new specs.

        

      


      
      

        

          terminal
          4. Immutable Ledger & Live SQL
        

        
What it does & When to use:

        

          Maintains an immutable SHA-256 audit trail of every past decision. The live SQL runner lets engineers execute relational queries directly against the in-browser AlaSQL database.
        

        

          
• Who can use: Auditors, Compliance Officers, Operations, and Database Engineers.

          
• How to navigate: Click 04 Ledger & SQL in the header.

          
• Key Buttons: Export JSON downloads audit logs; Run SQL executes arbitrary queries; Table presets quickly load table schemas.

        

      


      
      

        

          check_circle
          5. 12 Automated Verification Tests & Repository Bundler
        

        
What it does & When to use:

        

          Instantly proves system integrity by running 12 automated checks across prompt injection defense, fact extraction, TF-IDF matching, and AlaSQL relational storage.
          The Code Explorer lets developers inspect source files and download the entire full-stack Python + FastAPI repository in one portable ZIP file.
        

        

          
• Who can use: Software Developers, DevOps Engineers, and Security Auditors.

          
• How to navigate: Click 05 Checks in the header.

          
• Key Buttons: Re-Run Checks executes the test suite; Download (.zip) creates the standalone offline repository archive.
