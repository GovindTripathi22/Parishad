System Operational Manual: This guide provides a plain-English explanation of how Parishad works, where deterministic Python logic ends and generative AI begins, what every button does, who has permission to use each action, and how keyboard shortcuts speed up technical review.

1. The Core Mental Model: Deterministic vs. Advisory

Modern engineering organizations face a critical risk: as teams distribute across GitHub, Slack, and Jira, technical truth drifts. A pull request subtly changes battery sensor voltage from 54V to 60V, or a support policy shifts from 30 days to 14 days without stakeholder consensus.

Parishad solves this by acting as an autonomous company brain. Crucially, generative AI is NEVER given the authority to approve changes or rewrite documents on its own.

Authoritative Deterministic Logic
  • Fact and unit extraction with character span boundaries
  • Parameter-aware rule matching against certified baselines
  • Exact mathematical delta % calculation (with zero-baseline protection)
  • Role-Based Access Control (RBAC) enforcement
  • Optimistic concurrency version locks
  • SHA-256 chained hashing for the Decision Ledger
Advisory AI & Specialist Model
  • Dynamic cascading impact identification across cross-domain specs
  • Decision history precedent analysis
  • Targeted parameter diff drafting
  • Parishad Review Specialist (fine-tuned Qwen3.5-4B LoRA) for consistent structured reporting with 100% finding ID preservation
